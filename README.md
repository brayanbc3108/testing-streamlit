# Sellers Dashboard

A Streamlit dashboard built for the Testing Streamlit class activity. It reads sellers.xlsx and lets you filter by region, see KPIs and the sellers table, compare units sold, total sales and average sales by region and by seller, and look at one vendor against the average of the selected regions.

## Run locally

```
pip install -r requirements.txt
streamlit run app.py
```

Live app: LIVE_APP_URL

- app.py
